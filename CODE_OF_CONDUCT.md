# Community guidelines

Cham Linux welcomes people of different backgrounds, languages and experience
levels. Help make it a place where people can learn, ask questions and work
together safely.

- Treat others with respect; disagree with ideas without attacking people.
- Do not harass, discriminate, threaten or publish someone's private details.
- Explain technical risks clearly, especially for commands that alter a system.
- Respect consent, licenses and attribution when sharing code or artwork.
- Report security issues privately using [SECURITY.md](SECURITY.md).

Project maintainers may remove harmful content or restrict participation to
protect the community. For a private concern, use GitHub's private security
advisory mechanism where applicable; avoid posting personal information in a
public issue.
